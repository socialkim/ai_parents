키보드는 필요 없어요. 아이가 말하고 부모는 마이크 버튼만 눌러 주세요.

```
① 말하기  →  ② 살펴보기  →  ③ 다시 말하기  →  ④ 보여주기
```

## 이 페이지가 하는 일

북토크에서 소개한 수찬이(10세)의 실제 과정을 부모와 아이가 현장에서 따라 해 보는 페이지입니다.
수찬이는 길을 걷다 "만들고 싶은 게임 캐릭터가 있어요"라고 말했고, 아빠는 "그러면 그냥 해봐"라며 휴대폰을 켰어요.
말로 설명한 캐릭터가 그림이 되고, 영상이 되고, 친구가 해 볼 수 있는 게임이 됐습니다.

오늘 해 볼 일도 같습니다. **완벽한 프롬프트 한 번이 아니라, 결과를 보고 다시 말하는 경험**이에요.

## 구성 (약 25분)

| 탭 | 요금제 | 시간 | 하는 일 |
|---|---|---|---|
| 준비 | 무료 | 1분 | 부모 휴대폰 한 대, 받아쓰기 마이크(🎤) 찾기 |
| 몸풀기 | 무료 | 4분 | A. 가을 인사 카드 / B. 부모님 셀카로 만화 캐릭터 (둘 중 하나) |
| 그림 | 무료 | 7분 | 특징 세 가지 떠올리기 → 말하기 → "네 생각과 어디가 달라?" → 움직임 말하기 |
| 게임 | 무료 | 8분 | 퀴즈 · 별 모으기 · 리듬 게임 → 불편한 점 말하기 → 규칙 더하기 → 친구용 설명 |
| 영상 | Plus 이상 | 5분 | ChatGPT Work로 모션그래픽 영상 → 계획 먼저 고치기 → 보고 다시 말하기 |
| 고치는 말 | — | — | 더하기·빼기·바꾸기·크기·지키기·정확히 하기·되돌리기 + 부모의 질문 네 가지 |
| 우리 집 약속 | — | — | 저자 부부가 합의한 원칙, 개인정보 설정, 수찬이 실제 기록 링크 |

색칠된 상자를 누르면 문장이 복사됩니다. 소리 내어 따라 말해도 되고, 붙여넣어도 됩니다.

## 부모가 건네는 질문 네 가지

1. 무엇을 만들어 보고 싶어?
2. 꼭 들어갔으면 하는 특징은 뭐야?
3. 나온 결과가 네 생각과 어디가 달라?
4. 친구가 해 본다면 무엇을 알려줘야 할까?

## 현장 진행 팁

- 페이지 오른쪽 아래 **QR** 버튼을 누르면 이 주소의 QR이 크게 뜹니다. 화면에 띄워 두면 청중이 바로 따라 들어올 수 있어요.
- **가-/가+** 버튼으로 글자 크기를 조절할 수 있습니다.
- 완료 표시는 각자의 휴대폰 브라우저에만 저장됩니다.
