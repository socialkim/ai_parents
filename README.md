# 말로 만드는 AI 놀이 — 『AI 시대, 부모로 살아가기』 북토크 실습

아이가 말하고, 보고, 다시 말하면 그림·게임·영상이 되는 20분 실습 페이지.

- 그림 (ChatGPT 무료) · 게임 (ChatGPT 무료, 대화창 안 게임) · 영상 (ChatGPT Plus 이상, Work)
- 고치는 말 7가지 · 부모의 질문 4가지 · 우리 집 약속

## GitHub Pages로 올리기
1. GitHub에서 새 저장소 만들기 (Public)
2. `index.html` 업로드 (Add file → Upload files)
3. Settings → Pages → Branch: `main` / `/(root)` → Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 로 열림
5. 페이지 오른쪽 아래 **QR** 버튼을 누르면 현재 주소의 QR이 크게 뜹니다 (현장 화면에 띄우기용)

기능·요금제 구분은 2026년 10월 기준.
